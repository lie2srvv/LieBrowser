# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability or privacy flaw in LieBrowser, please responsibly disclose it by opening a private security advisory on GitHub or by contacting the project maintainer:

* **GitHub Security Advisory / Issues:** [Create an issue](https://github.com/lie2srvv/LieBrowser/issues)
* **Telegram:** [@lie2srvv](https://t.me/lie2srvv)

Please include detailed reproduction steps and device details so we can address and patch the issue promptly.
